# MA 小电流闭环实测与 MATLAB 初调

日期：2026-10-19。开发机分支 `test/foc_current`；未合入 main。
实物：小车架空，左侧 MA 卸去轮毂；MB 三个 PWM 引脚保持输入下拉。
最终状态：测试结束，`running=0`、`requested=0`；上电默认停止。

## 电机参数的依据

用户用正点原子 LT1 电桥镊子，在两根电机线之间测得 **180 mΩ、48 μH，第三根悬空**。用户未记得调整过档位参数，且同方法测另一台有官方参数的电机曾得到相符结果。

因此保留这两个测量值，以等效星形模型的每相 **R=90 mΩ、L=24 μH** 作为初调起点。测试频率、DCR/交流串联电阻模式未记录；这里没有把它们宣称为辨识完成的 Rs/Ld/Lq，也没有确认物理绕组接法。原记录位于 `matlab/FOC电机仿真/foc_parameters.m`。

PI 初值采用 `Kp=L·2πfc`、`Ki=R·2πfc`，再用实物阶跃核查。公式参考 [SimpleFOC 电流环整定](https://docs.simplefoc.com/tuning_current_loop)。以前理想仿真的 500 Hz 没有直接照搬。

## 本轮实际改动

1. α、β 静态电压矢量测试发现两路电流反馈符号均反向，先把控制坐标中的换算增益修正为 **−4 A/V**。A/B 相映射与相对电流比例通过实测核对，绝对安培增益仍是电路标称值。
2. 从开环合成角切换为左编码器角度：`theta=wrap(-7*encoder_angle-zero)`，按采样时间戳外推编码器角度。临时零位 `zero=5.330672807 rad`，主机每次复位后显式下发。齿槽转矩、摩擦造成的对齐误差尚未精细辨识。
3. core1 保留 sensor/FOC 自由循环；PI 仅对新的有效 A/B 电流更新，积分使用实际采样时间差。无效样本不积分、不发布新电流命令；超期则停止。
4. PWM 仍为 **10 kHz**。计数时钟从 10 MHz 提至 **80 MHz**，完整上/下计数周期从 1000 提至 8000 tick，峰值 4000。三相比较值用带版本号的完整命令传递，不再塞入原先 30 bit 打包值。
5. ADC 辅助定时器在主 TEZ 后名义 **30 μs** 触发顺序 A/B 采样；名义 **80 μs** 的提交中断是唯一比较值写入者，整组三相在后续 TEZ 生效。错过提交时隙就保留旧命令，避免跨 TEZ 分相更新。

在约 8.1 V 母线下，每格占空比对应的理想电压步长约由 **16.2 mV 降至 2.0 mV**。这比先滤平电流曲线更直接地改善了小电流执行分辨率。

## 已完成的带电试验

所有试验均有限时、默认停止，不启动速度环或平衡环。

| 数据名 | 实际命令 | 用途 |
|---|---|---|
| cal_006 | CAL 0.06 900 5 | 原符号下的静态矢量核查，发现极性相反 |
| cal_010 | CAL 0.10 900 5 | 修正符号后复核相映射、编码器方向与临时零位 |
| d_100hz_raw | DTEST 0.30 350 2 | 10 MHz 计数、100 Hz 设计 PI 的基线 |
| d_100hz_hires | DTEST 0.30 350 2 | 80 MHz 计数、相同 PI 的单变量对照 |
| d_200hz_hires | DTEST 0.30 350 2 | 80 MHz 计数、200 Hz 设计 PI |
| q_200hz_hires | QTEST 0.10 240 2 | d 指令 0.15 A，q 正负 0.10 A、20 ms 短脉冲 |
| d_200hz_final | DTEST 0.30 350 2 | 最终 v8 默认参数复测，修正运行期提交统计 |

DTEST 的 d 指令为 0→0.15→0.30→0.15→0 A，q 指令为零。保存数据抽取率约 5 kHz，带电采样有效率由 ISR 的全速计数统计，并非仅统计保存的行。

三组对照统一采用运行时间 **0.14–0.19 s** 的原始反馈统计，无反馈滤波：

| PWM 计数时钟 / PI 设计带宽 | Id 均值 | Id 标准差 | Iq 标准差 |
|---|---:|---:|---:|
| 10 MHz / 100 Hz | 0.29990 A | 40.21 mA | 28.03 mA |
| 80 MHz / 100 Hz | 0.29974 A | 12.19 mA | 15.43 mA |
| 80 MHz / 200 Hz | 0.29981 A | 9.95 mA | 15.54 mA |

这几组均为 3499/3499 次带电 A/B 对通过软件窗口判定，无过流或跨 TEZ。单次试验的统计不足以证明所有工况下 200 Hz 的噪声优于 100 Hz，但清楚显示提高 PWM 分辨率的收益。

MATLAB 对 0.15→0.30 A 阶跃作经验一阶拟合：高分辨率 100 Hz 参数约 τ=1.45 ms，200 Hz 参数约 τ=0.93 ms；最终复测 τ=0.96 ms。它们是含延迟及非线性的闭环近似，**不是电机电感辨识，也不是扫频测得的正式带宽**。

q 轴脉冲末 10 ms 的均值：正指令两次约 +0.107/+0.106 A，负指令约 −0.105/−0.113 A；d 轴仍约 0.15 A。电机发生小幅运动，q 轴存在约 5–13 mA 的运动工况跟踪偏差，不能宣称已完成转矩标定或全速度范围整定。

最终复测 v8：全速有效 **3499/3499**，PI 更新 3499 次，最大有效更新时间间隔 101 μs，比较值 API 错误 0，运行期提交时隙错过 1 次，未触发保护。保存样本中计算完成年龄中位 54 μs、95 分位 57 μs；所用采样时间戳至 PWM 生效约 69–70 μs。前几轮也出现过 170/270 μs 的路径，因此不能把最终单轮的 70 μs 当成跨启动、跨负载的硬时限保证。

## 发现的实际限制与下一步

- 最终版本复测前，串口打开引起的启动中两次出现左编码器时间戳不再更新。固件以 `ERROR sensor/bus` 拒绝测试，未进入带电。显式 RTS 复位并在同一串口会话检查后恢复，最终复测完成。`rejected_stale_encoder.log` 保存了证据。**启动时 I2C/编码器恢复机制应优先修复**，不能靠降低新鲜度检查绕过。
- 现有采样窗口判定使用已生效比较值及完整 A/B 转换区间，保留 2 μs 保护量；本轮没有示波器，因此有效率不等同于已经证实模拟前端全部建立、死区无影响。
- 电流增益尚未用外部电流仪表标定；2 A 是采样后的软件停机阈值，不是瞬时硬件限流。GPIO 全低是低侧制动零矢量，不是三相所有管子关闭。
- 临时电角度零位尚有摩擦/齿槽误差；进入正式控制前应加入足够缓慢的双向对齐核查。
- 下一阶段先解决编码器冷启动，再在同一小电流范围复核 `Id=0` 下的 q 阶跃、多个转子位置与低速转动；逐步扩大电流，并视运动偏差加入反电势/交叉耦合前馈。然后独立校准 MB，最后接速度环、平衡环。当前只证明 MA 小电流闭环初调通过。

## 文件及复现

- `foc_current.cpp/.h`、`test.cpp`：开发机当前 v8 的源码副本。
- `v6_baseline/`、`v7_hires/`：关键历史版本；`initial_positive_sense.cpp` 是发现极性问题的首轮版本。
- `prepare.py` 生成 v6 模板版；`prepare_highres.py` 从留存的 v6 版本生成当前 v8。
- `run.py` 在开发机使用 IDF Python/pyserial 执行有限时命令。它先确认停止、等待设置应答，固件再检查编码器和母线；测试结束显式 STOP，之后才 DUMP。
- 每轮 `.log/.csv/.json` 保存串口原文、样本、ADC 校准 LUT 和全速统计。
- `analyze_current.m`、`compare_current.m` 是离线 MATLAB 分析，不启动电机；对应 `.fig/.mat/.png` 可直接重开。
- `calibration.json` 记录 LT1 原始参数、等效模型及此次极性/零位结果。
