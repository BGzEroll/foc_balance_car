# 电流环探索结果如何提取到 main

2026-10-19 用户确定本阶段采用 v18 的 sensor＋FOC 合并轮询，不再以拆分任务作为本轮优化目标。实验分支用于寻找电流 PI 参数与实现路径，不是整车最终应用；本次不合入或修改 main。

## 固定的调度和数据路径

- core0 的 MCPWM 中断按既定时序采 ADC、检查窗口、发布完整 A/B 电流组，并提交完整 PWM 命令。10kHz PWM 逐周期交替电机，每台名义5kHz采样。
- core1 一个优先级5的任务：先非阻塞消费 I²C 完成通知、发布传感器结果，再检查两台电机的新电流组，计算电角度、PI和调制。
- I²C 是异步传输，合并任务用零超时检查完成事件；没有完成就返回。taskYIELD() 不代表阻塞，也不能保证低优先级或 Idle 获得运行时间。
- 每台独立保存采样序号、时间戳、积分、电角度标定和命令序号。只对新且有效的完整组计算一次；积分使用实际 dt，而非假定永远200μs。
- 角度按编码器时间戳对齐至电流采样时刻。数据过期时停机，不用重复旧样本维持表面上的固定计算频率。

## 参数含义

电流 PI：`V = Kp*(Iref-I) + integral`，积分增量为 `Ki*dt*(Iref-I)`。

- Kp 单位 V/A；Ki 单位 V/(A·s)，不是每次迭代直接叠加的系数。
- 本轮 d/q 共用同一组参数，电流不额外低通；不能把测试标签里的设计频率当作实测闭环带宽。
- 速度外环的0.20/0.40和±0.70A限制只用于架空速度对照，不等于最终平衡控制器参数。
- 当前电流使用标称增益换算；两台电机电角度零位和方向需各自保存，机械前进方向仍需在车辆坐标中映射。

## 必须一同提取的行为

动态电压矢量上限、矢量缩放后的积分回算、启动时完整命令同步生效、无效窗口拒绝、采样/角度/任务/母线过期停机、有限时或明确状态控制。不要只复制 Kp/Ki 而丢掉这些行为。

`Vlimit = min(本阶段绝对上限, ratio*Vbus)` 是当前实验与固定采样窗口的约束，不是对最终小车永久只允许0.40V的要求。扩大输出范围时需同时评估采样有效率、饱和和电流表现，不能仅删除限幅。

## 与整车应用的衔接

外环按其传感器节拍产生电流目标；电流环消费目标并限制输出。串口测试台、DUMP、大块记录缓冲区和临时运行命令不用照搬。正式业务加入后，重新检查最坏 PI 间隔、编码器年龄和低优先级任务余量；本次不把这个工作扩展成产品架构改造。

没有示波器不阻塞本阶段参数探索。实测可用结论仅覆盖记录的电流、转速、母线与架空轮组状态；软件判窗不等于外部仪器确认。
