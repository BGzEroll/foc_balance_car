# ±5cm 动态测试

用户允许动态测试，约束前进、后退不超过 20cm。首次轨迹为 +5cm、0、-5cm、0；每段六秒五次平滑移动、六秒保持，总计 48s。参考最高速度 1.5625cm/s，参考最高加速度约 0.802cm/s²。不使用直接电流 PROBE 代替闭环运动。

`motion_test.h` 仅在显式 DYNTEST 后生成参考，起点为当时控制器里程。10cm 估计位移触发提前中止并参考回原位，15cm 触发停止输出。5cm 计划行程及提前处理给 20cm 留出余量，但编码器估计不能独立证明地面位移或消除惯性、打滑误差。测试完毕 DYNEND 解除专用边界，恢复普通连续平衡；原 6A、倾角、数据新鲜度等保护不变，没有恢复旧的编码器限速停机。

60001 个时间点的本机检查验证轨迹、参考速度导数、加速度、端点和位移处理。MATLAB 使用当前保留矩阵、Kt=0.7/1/1.3、10ms 指令延迟、3ms 电流滞后和噪声筛选通过；这只是模型筛选，首次实测揭示了明显偏差。

开发机编译、USB/IP 烧录和回读通过，镜像 SHA256：`fdb52dc8e885ea7368960a94c70009b3dfa7064cb12b2f6a8d8e2c8481547184`。正常校准后重载保留参数，用户确认开启后进行测试。

## 首次实测：轨迹执行完成，动态跟踪未通过

| 指标 | 结果 |

| 每轮目标电流峰值 | 1.855A |

没有故障、目标电流限幅或动态位移中止。参考速度与固件目标速度遥测最大差约 6.9e-10m/s，说明轨迹指令确实应用。前移段末尾的估计位置约 -0.98cm，而参考为 +5cm；后退段出现超调，说明静止平衡改善不能当作动态跟踪改善。该记录本身不足以断定物理方向映射反了，平衡对象也存在初始反向响应。

轨迹结束后 17s 观察窗口内，未达到“位置误差小于 5mm、速度小于 1cm/s，连续两秒”的回稳标准。不能将无故障称为动态测试通过。

结束时已执行 DYNEND、核对 armed=0；小车保持连续平衡并继续记录。首次测试后未直接保留新的增益，随后继续了下面的模型筛选及实机优化。实机数据位于 `results/dynamic/first_run/`，包括 200Hz 原始样本、事件、轨迹重建、分析 JSON 和 MATLAB 图，可用于校正机械/摩擦/测量动态模型。

## 换向积分处理

新增 `motion_integral.h`：启动/结束相对位置轨迹时平移积分状态，抵消参考原点变化产生的电流跳变；`DYNINT` 默认 0，在线候选 0.04/0.08m·s 限制的是运动期间相对原有平衡积分的增量，并在第 12、36 秒方向反转后的 1 秒内以 0.3s 时间常数平滑释放增量。运动结束时不强制清空原平衡积分。普通连续静止平衡逻辑不启用这段处理。

MATLAB `screen_motion_integral` 可复现筛选：在 0.1N 摩擦假设下，0.04 候选的轨迹误差 RMS 8.46→6.72mm；在 0.4N 假设下，误差 27.24→28.69mm 略差，但俯仰峰值 7.88→5.76°，尾部位置偏差 11.42mm→约 0。六个模型情形均无倾倒，但这是参数假设筛选，尚非辨识后的真实对象。简单地在结束后释放积分的另一方案因低摩擦尾部误差变大而被否决。

原生检查 201 个状态验证参考平移代数、积分释放与关闭时不变。开发机编译和烧录回读通过，当前积分试验固件 SHA256：`89b4e502e98a1e0a23cbf6831951997462e67507415167f03806919ae6304c70`。正常校准后，在同一轮校准下执行 0→0.04→0 的实机往返比较；结果见后续记录。`main` 未变。

`analyze_feedback_spectrum.py` 分解 A2 的 48–65s 恢复段：角速度主峰 10.0Hz；8–30Hz 角速度反馈分量 RMS 0.515A，速度反馈分量 0.264A，共模目标电流 RMS 0.507A。这些闭环量相关，分量 RMS 不能相加，也不能直接辨识真实机械原因。由此增加一个只将角速度反馈 ×0.85 的候选；MATLAB 含 Kt 0.7/1/1.3、0–2 周期延迟等线性筛选最大极点模 0.9964844，原非线性有噪声往返筛选通过。随后进行同轮校准实机比较。


基础矩阵核对：一度怀疑 `design_lqi` 与固件导出不同。MATLAB 逐项比较确认 `max(abs(K_design-K_exported))=0`，这一怀疑已撤回，旧筛选没有因矩阵数值失配而作废。新增 `hardware_lqi_design` 显式加载导出矩阵，并自动核对设计 SHA 和保存后的实际 K，防止以后漂移。重新筛选数值与原先一致。

角速度反馈 ×0.85 首轮：位置误差 RMS 1.399cm，速度误差 RMS 1.936cm/s，恢复位置 RMS 4.794mm、恢复速度 RMS 2.164cm/s，17s 内未严格回稳。恢复段 8–30Hz 共模目标电流 RMS 相对 A2 从 0.507A 降到 0.336A，但其他指标没有同步改善，不能据单一频段指标保留。已恢复原矩阵。实测文件在 `results/dynamic/rate_085/`。
