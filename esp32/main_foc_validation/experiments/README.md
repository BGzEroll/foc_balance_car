# 中间试验，非最终方案

这里保留前期事件等待、分任务、分核、计时诊断的源码快照，便于核对失败日志。它们不在当前 CMake 构建列表内，不应代替最终固件。

最终方案恢复 v18 的 core1 合并轮询、priority 5、每电机 5 kHz 采样与实际 dt 积分；关键修复是补回 v18 的 `-O2`、整个 FOC 与数学函数 noflash 链接配置、MCPWM 控制函数 IRAM 配置，以及相同的 Idle1 设置。

`prepare_minimal.py` 是历史中间候选生成器，已经禁止执行，避免覆盖最终修复。请使用上级目录的 `remote.py`、`run_new.py`、`gate.py`。

早期 `task_state` 字段不能统一用于调度结论：部分旧测试台版本曾将它作为占位。最终固件已移除此字段，改为实际 `pi_updates` 计数。运行、故障和样本有效性以各轮原始日志、JSON、CSV 为准。
