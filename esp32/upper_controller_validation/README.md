每段记录为 10 秒、40 Hz 的快照，控制本身保持 200 Hz。统一去掉记录段开头两秒后比较：

B 组相对原参数的俯仰 RMS 下降约 70.5%，波动标准差下降约 88.3%。这是同一实物的快速观察性整定，不是重复统计试验；初始姿态及人工接触条件存在差异。未完成长时、行驶、坡道与扰动验证。

源控制器输出以等效力矩调参，再通过条件辨识的 `Kt=0.0133119595 Nm/A` 换算。原速度环在本次 0.7 A 实机限流下使目标俯仰快速变化，并长时间触及限流；减缓速度 PI、增加俯仰阻尼后摆动明显下降。不能将这一表现归因于 FOC 核心失效：5 ms 全量轨迹中，电流与上一周期目标的 RMS 误差约 MA 0.019 A、MB 0.020 A。

## 实现与证据

- `balance.cpp/h`：位置 P → 速度 PI → 俯仰 PID，独立偏航 PID，保留积分限幅与抗饱和逻辑。
- 坐标：硬件右/前/上转换为控制器前/左/上；包含同时横滚、俯仰时的耦合关系。轮子前进对应 Iq 符号为 MA -1、MB +1，轮速还乘各自校准方向。
- `reference/` 为 `test/foc_current@207729f` 中未经修改的 MATLAB 参考源与参数快照。
- `results/native_summary.json`：14,400 个 PID 样本、6,000 个坐标转换样本。最大指令误差 0.0000282 A，坐标转换最大角度误差约 0.00000029 rad。
- `results/quick_tuning_summary.json`：上述三组定量比较。
- `results/continuous_balance_0_0_7_window_1.*`、`window_2.*`：A/B 在线整定快照。B 段累计 32,512 次更新，最大全程周期 5,039 μs，最大全程计算 248 μs。
- `results/build_identity.json`：最新构建与本地/开发机代码摘要；`flashed_build_identity.json`：连续试验使用的固件摘要。B 通过串口在线应用，随后将源代码默认值改为 B 并重新编译，未为写默认值中断连续运行。

记录中的电流快照先于同一行新指令的提交；40 Hz 抽样不能直接用同一行之差作为电流环动态跟踪误差。停机或未使能电机的电流也可能是旧快照，应结合 `current_age_*_us` 判断。

## 连续运行与串口

上电保持停机。车身静止、两轮自由悬空时执行 `CAL`，确认 `calibrated=1` 且方向与当前硬件基线一致后再落地。曾在校准受运动干扰时得到 MB -1，重新静止校准恢复 +1；不能把受干扰的校准直接用于平衡。

```text
STATUS
CAL
BALANCE 0 0.7
TUNE 0.5 0.2 0.05
DUMP
STOP
```

`BALANCE 0 0.7` 连续运行，正常运行没有时长截止；`TUNE` 在线生效；`DUMP` 复制滚动缓冲区后后台导出，控制继续执行。保留倾角、轮速、传感器、电流及任务故障保护。连续模式由上层每 5 ms 续期，只有控制失联超过 30 ms 才由 PWM 截止保护停止。

早期限时验证曾在 10 秒结束时断力导致小车倒下，用户要求后已加入连续模式。今后正常平衡使用上面的 0 时长命令。主动 STOP 或结束串口辅助进程前应先拿稳小车。辅助进程退出会发送 STOP；本次按用户要求保持进程及连续平衡运行。
