# LQR参数计算

打开 `calculate_lqr.m`，在顶部两个“可修改”区域中修改参数，保存并点击MATLAB的“运行”。K矩阵会显示在命令窗口，不生成额外窗口或文件。

默认机械参数取自 `模型/参数与图片/机械参数.json`，已明确列为可编辑数值。车身质量含定子；单轮组质量不含定子。俯仰惯量绕车身质心，单轮惯量绕驱动轴；偏航惯量是含轮组贡献的整车有效惯量。长度使用m，质量kg，惯量kg·m²，角度rad。

| K的列 | 状态 | 单位 |
|---|---|---|
| 1 | 纵向路程s | m |
| 2 | 纵向速度v | m/s |
| 3 | 俯仰角减静态平衡角 | rad |
| 4 | 俯仰角速度 | rad/s |
| 5 | 偏航角 | rad |
| 6 | 偏航角速度 | rad/s |

Q是6×6状态权重，R是2×2输入权重。Q需对称半正定，R需对称正定。当前机械模型采用左右轮组对称的假设。

K是2×6矩阵，对应控制律：

```matlab
u = -K * (state - reference);
tau_left  = (u(1) - u(2))/2;
tau_right = (u(1) + u(2))/2;
```

第一行生成总转矩，第二行生成右轮减左轮的差转矩，单位N·m。采样周期Ts影响离散化和K；单轮限幅只用于仿真执行，不参与无约束LQR求解。

`solve_balance_lqr.m`负责线性模型、精确离散化和dlqr求解，通常无需修改。`design_balance_suite.m`是3D仿真调用接口，调用相同参数入口，不会另外维护一份K。

修改这些参数不修改3D模型实体。闭环特征值稳定只证明设计用的离散线性系统稳定，实际3D表现仍需运行工况验证。
