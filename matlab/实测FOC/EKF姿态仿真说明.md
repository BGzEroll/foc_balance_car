# EKF姿态估计仿真

这是在现有PID + FOC + Multibody模型中增加的可选姿态估计器。选择 `ekf` 才会启用；默认仍为 `legacy`。它不是新控制器，也没有给电流增加低通。

运行 `run_ekf_comparison` 后台计算，完成后运行 `show_ekf_comparison` 打开曲线和三维机械真值回放。结果、固定参数、单元检查和运行进度在 `ekf_validation/summary.json`；各次完整结果位于独立的 `results/*_ekf_ekf_comparison/`。

## EKF在这里估计什么

名义状态为机体到世界的四元数 `[w x y z]` 和三轴陀螺零偏。协方差对应六维误差状态 `[姿态小角误差(3), 零偏误差(3)]`。使用乘法误差状态EKF（MEKF/ESKF），每次更新把小角误差注入四元数并重置局部误差坐标。这里没有位置、速度或线加速度状态。

1. 预测：用“陀螺读数减估计零偏”积分四元数，并传播6×6协方差。
2. 观测：比较加速度测得的归一化比力方向和预测重力方向。
3. 更新：用Kalman增益修正姿态、零偏，使用Joseph形式更新协方差，随后做误差注入后的协方差重置。

右乘姿态误差约定下，线性化矩阵为：

```text
F = [-skew(gyro-bias), -I; 0, 0]
H = [skew(predictedGravity), 0]
```

每帧陀螺噪声先验以 `sigma²*dt²` 加入姿态过程协方差，零偏随机游走密度以 `sigmaBias²*dt` 加入零偏过程协方差。不要把这两种噪声单位混用。

## 固定参数与限制

`measured_ekf_parameters.m`集中保存参数：每帧陀螺标准差0.005rad/s、零偏随机游走密度0.00002rad/s/√s、归一化加速度方向标准差0.02、初始姿态标准差2°、初始零偏标准差0.5°/s。这些是保守仿真先验，未宣称由独立实测辨识，也没有根据测试真值逐条优化。

加速度模长偏离校准后的1g超过20%时跳过重力观测；模长异常或方向创新增大时增大R。这是对线加速度污染的启发式降权，不是已知的真实线加速度补偿。加速度归一化后的实际噪声也不是严格各向同性，这里使用保守各向同性近似。实际有色、与速度有关的噪声不完全符合白高斯模型；不能把P直接当成已验证的统计置信区间。

控制器收到EKF姿态和扣除估计零偏的角速度，这是估计器更换的一部分。位置/速度/俯仰/偏航PID和FOC参数均不变。估计器只在200Hz的新IMU帧更新。

只有重力观测时绝对航向不可观。在静止竖直状态下，绕重力方向的陀螺零偏也不可观。EKF能校正可观方向，不会自动解决偏航漂移；若要稳定的绝对航向，需要额外的磁力计、外部航向或其他有效约束。

## 对照与验证范围

先运行观测Jacobian有限差分、静止倾斜/零偏收敛、协方差正定性、四元数归一化、q与-q等价以及偏航不可观检查。通过后跑4秒3°倾斜恢复、10秒前进转弯，PID/IMU200Hz、机械步长250µs、电流上限6A、同一噪声随机种子。

旧算法和四元数互补的完整机械结果只有在原始MAT存在且PID、FOC、传感器参数、步长和时长匹配时才复用。本次工作区保留了昨天的报告和图，但原始MAT已经不在，因此三种算法共六次闭环运行将全部重新计算。脚本支持复用本次已完成且参数匹配的运行，以便失败恢复。估计误差只在真值与控制器日志共同时间区间计算，不外推末端。比较的是各自闭环轨迹，因此误差变化同时受轨迹变化影响；单次固定噪声种子不能证明统计优势。高速、复杂地形、参数敏感性和实车表现还未验证。

示例：

```matlab
balance_setup
run_measured_car('route',false,0,true,250e-6,10,'selected','explore6',0,.005,'ekf','manual')
```

方法参考：[Quaternion kinematics for the error-state Kalman filter](https://arxiv.org/abs/1711.02508)、[MathWorks IMU Filter](https://www.mathworks.com/help/nav/ref/imufilter.html)。这里是自有六误差状态实现，没有直接调用MathWorks的九误差状态imufilter，二者不能视为同一个算法。

结论：本版EKF能在闭环运行，但目前固定参数和六误差状态模型并未优于互补滤波。恢复场景的偏航估计稍好，俯仰估计却明显变差；转弯约5秒后出现持续振荡，俯仰、偏航、倾角、电流均恶化，末端真实航向误差超过现有2°门槛。因此继续保留原默认算法，EKF仅作为实验可选项；不要把“未倒下”写成验收通过，也不能由本次结果推断所有EKF都不适用。

单元检查通过不等于动态模型匹配。本实现的候选原因是动态比力、有色噪声和传感器带宽/延迟与简化重力观测、零偏模型不匹配，可能让真实运动误差进入姿态或零偏估计。这是待验证的解释，当前没有保存逐帧EKF偏置、创新和协方差日志，不能认定已找到根因。后续应先记录这些量并做同一段IMU数据的开环回放、检查Q/R敏感度和动态加速度建模，再考虑是否值得继续闭环调参。

完整指标与图位于 `ekf_validation/comparison.csv`、`summary.json`、`comparison.png` 和 `comparison.fig`。4秒恢复和10秒温和转弯、单一固定噪声种子是本次全部闭环验证范围，未进行实车验证。
