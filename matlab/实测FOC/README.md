# PID + 实测FOC与传感器驱动的3D小车

2026-10-20已迁入当前项目的`matlab/实测FOC/`，模型、源码、参数、报告及已保存结果均在本目录下。入口是`launch_measured_car.m`，回放是`replay_measured_course`。运行路径根据本文件所在项目自动确定，不依赖原独立工作区；历史结果MAT/JSON中保存的旧绝对路径仅保留为当时的参数记录。迁移验证见`migration_validation.json`。

2026-10-19。模型基于当前v18实物测试数据，电流PI已由用户确认采用base：Kp=0.060318579 V/A、Ki=226.194672 V/(A·s)，D=0，无额外电流低通、无解耦前馈。模型单独放置，保留原来的理想执行器模型。

## 运行

在MATLAB中打开本目录的`launch_measured_car.m`并运行，即可打开PID专用面板。默认综合场景39秒，单侧6A探索档；可直接回放已保存的机械真值，不需要重复长时间计算。需要Simulink、Simscape、Simscape Multibody及原项目依赖。当前公开入口与新模型只使用PID；旧LQR设计脚本与旧模型作为历史资料保留。

三维外观需要Git LFS实际网格，不能使用只有`version https://git-lfs...`文本的占位文件。本机工作区已从原仓库按LFS SHA256核对并补齐网格。入口与模型加载回调均自动添加网格路径；若动画时间轴不在屏幕内，先最大化Multibody Explorer，再使用底部播放键。

```matlab
addpath('本目录的绝对路径')
launch_measured_car
replay_measured_course % 已保存的原生Multibody位姿 + 原模型STL，可拖动时间轴
[o,r]=run_measured_car('mixed',false,0,true,500e-6,39,'selected','explore6');
[o,r]=run_measured_car('limit',false,0,true,500e-6,7,'selected','explore6',2.5);
[o,r]=run_measured_car('recover',true,3,true);
[o,r]=run_measured_car('drive',false,3,true);
[o,r]=run_measured_car('turn',false,3,true);
% 第4项关闭观测噪声；电流采样扰动仍保留
[o,r]=run_measured_car('recover',false,3,false);
% 比较250us机械宏步长；第6项可缩短数值收敛检查时长
[o,r]=run_measured_car('recover',false,3,true,250e-6,2);
```

`build_measured_car`重新生成`balance_car_pid_foc.slx`，嵌入PID、FOC、传感器函数。修改这些图内函数后需要重建模型。`run_measured_car`每次写入当前参数，结果位于`results/工况_.../`，包含MAT原始结果、CSV、PNG、原生FIG和JSON。第3项初始倾角只对recover生效；结果目录保留请求参数，报告另写实际初始偏差。报告同时检查机械真实状态和控制器估计状态。完整综合场景可能需要数十分钟，日志每20秒显示仿真进度。

## 当前场景与上层PID

上层PID默认周期现为1ms（1kHz），包含位置P、速度PI、俯仰PID和偏航PID。编码器观测也按1ms读取；IMU、44Hz信号带宽近似、AR12创新和互补姿态滤波仍只在5ms处更新，中间保持最近一帧。`PID_observation`只更新当前时刻与编码器速度，不在重复IMU帧上额外推进滤波或噪声。积分每次使用实际配置的1ms，俯仰/偏航微分继续使用陀螺角速度；没有把增益乘以5，也没有改变base电流PI、每侧5kHz电流更新和50us电气积分。

面板可选1ms默认或5ms历史周期对照。命令行第10项可指定周期；生成结果目录带`_pid1000us`/`_pid5000us`，避免覆盖旧结果。每次仿真StartFcn检查编译后真实执行周期，并保存PID时钟日志；新验证见`pid_rate_validation/`。以下原200Hz测试数字及2.5/4m/s边界保留为历史证据，不能直接冒充1kHz结论。

当前周期的配置入口是`measured_pid_config.m`；共用的`3D仿真/pid_balance_parameters.m`和纵向预筛脚本保留历史5ms默认值，当前原生模型会显式覆盖，不依据这些旧默认值判断实际执行频率。

后台验证已完成：1kHz跑满39秒功能场景，并通过0.7A、3度倾斜的6秒恢复检查。相同250us机械步长下，快速段速度RMS由0.05763降至0.05676m/s（约1.51%），两侧Iq跟踪RMS由[0.0296,0.0429]升至[0.0516,0.0805]A，说明收益与电流指令边沿跟踪之间有取舍。1kHz的500/250us姿态差为0.259度，仍超过原0.15度目标；严格资格没有改为通过。完整结果与图见[周期验证报告](pid_rate_validation/README.md)。

```matlab
% 后台计算，不打开模型或3D窗口；第9项只在limit压力场景中使用
[o,r]=run_measured_car('mixed',false,0,true,500e-6,39,'selected','explore6',0,1e-3);
[o,r]=run_measured_car('mixed',false,0,true,500e-6,39,'selected','explore6',0,5e-3);
```

控制链：位置P → 速度PI → 俯仰PID，加独立偏航PID → 左右目标Iq → 固定base电流PI → 原生Multibody轮组/接触。FOC使用实际电气状态，控制器使用带扰动观测。

综合场景包含1.48m/s峰值指令、0.094m/s慢行、12°坡中停车4秒、10.6cm高平台、下坡、左3mm/右2mm交错凸起、1mm整轮减速带、倒车、原地转向、弧线转弯以及外力/偏航推扰。六块地形都有独立真实接触力记录；不是仅更换可视化地面。

候选PID保留位置P=1.3、俯仰P/I=0.4/0.005、偏航P/I/D=0.105/0.01/0.02；速度P由1.0调到1.4，速度I由0.03调到1.2，俯仰D由0.04调到0.025。前述转矩相关增益保持原Nm约定，通过条件Kt显式换算为A；完整配置见`pid_selected_parameters.json`。先使用101组非线性纵向简化模型预筛，再在完整3D验证，不能把预筛边界当作实际极限。

相同6A和电压包络下，完整3D快速段速度RMS由0.1012降至0.0568m/s，12°坡停平均世界Y误差由-15.57cm降至-2.66cm。原参数只跑前14.5秒作对照；候选参数跑满39秒，六地形、坡停、快慢速、双向转弯均完成，真实俯仰峰值19.52°、横滚1.51°，实际Iq瞬时峰值6.07A。它是本场景候选，不是最终实车上层PID。

保留严格检查的未通过结果：完整场景原水平路程对轮行程门槛为3cm，原始差值4.24cm；轮行程与水平投影之间仅坡面几何就相差2.23cm，统一定义后剩余约2.01cm，实际轮轴3D路径对指令差约1.93cm。详见`pid_validation/odometry_audit.json`。原指标没有被悄悄放宽，`summary.json`分别标注功能完成和严格验收；当前严格验收未通过。

原生3D独立平地压力测试：2.5m/s指令达到真实峰值2.611m/s、真实俯仰32.32°、Iq峰值1.79A，按该工况门槛通过；4m/s指令达到4.178m/s，但真实俯仰51.07°，观测约35.18°，未通过。后者Iq峰值仅2.50A且电压未饱和，暴露了加速时比力污染互补姿态估计及控制能力边界，单纯提高电流上限不能解决。上述为500us快速探索结果，不能宣称绝对极限速度。

## 电流与电压探索档

`bench`保留0.7A及min(0.40V,0.04Vbus)台架限制。`explore1p5`、`explore3`、`explore6`、`explore10`分别把单侧指令上限改为1.5/3/6/10A，并使用0.45Vbus电压矢量上限：8.03V时为3.6135V，随母线参数变化。电流PI一直为实测base。这些配置只写入仿真参数；实物固件与限流未改变。

允许10A不意味着运动时一定需要10A。模型仍保留反电势、电阻、电压/PWM限制、电流动态与轮胎接触摩擦；过大的目标最终受到这些约束。`validate_exploration_foc`还检查6.4/8.03V、0.5/1/1.5倍电感先验及0.7/3/6/10A阶跃，但这属于电气模型内部压力检查，不能替代高电流实测或热验证。

## 传感器噪声、零偏与振动

本次架空MA无轮、MB带轮，共6000帧：静止4800帧（分8段、累计约24秒），10/20rad/s各600帧。完整采集说明与原始记录在实验分支`esp32/current_loop/sensor_noise/`。本目录`data/sensor_noise/`另存10段CSV、元数据、分析脚本与图，便于模型独立复现；运行其中`analyze_sensor_noise.m`离线重算，再将生成的参数JSON复制到本目录。诊断固件与烧录证据仍由实验分支保存。

静止加速度标准差约[1.477,1.344,2.161]mg，陀螺约[0.0331,0.0370,0.0312]deg/s；保留校准后的平均残余陀螺零偏。转动时40～60Hz附近明显振动，且10rad/s加速度波动高于20rad/s，因此采用静止/10/20三组稳定AR12输出随速度混合，保留有色频谱与轴间创新相关。超出20rad/s采用20档边界值，没有宣称更高速噪声已验证。

静止比力模长只有约0.8883g。本版把它保留为共同加速度比例的单姿态等效先验，未把它当成随机噪声，也没有宣称完成六面校准。振动包含架空夹具和车体真实微动，不能直接等同于芯片噪声或落地行驶振动；它作为观测扰动注入，没有再当成机械外力重复施加。

真实机械运动转换为机体系比力和角速度，加信号带宽、经验扰动、偏置和量化，最后使用原固件0.02加速度权重的互补滤波。控制器使用该姿态和编码器里程，报告另外保留机械真值，防止估计平稳掩盖真实漂移。

## 数值方法和验证范围

平均逆变器保留PWM比较值量化/上下限、电压矢量限幅、积分回算、输出延迟和dq电机状态。电气积分50µs，每步分两次RK4；默认机械宏步长250µs，期间外推轴角并向Multibody交换平均净转矩。宏步长必须是50µs的整数倍，并同时整除1ms PID周期和5ms IMU周期。左右电机惯量由原机械轮组实体承担，执行器不重复积分机械惯量；整车两轮的摩擦均取实测MB带轮候选值。

500µs与250µs在前2秒的峰值姿态差约0.204°、前向位置差约1.18mm，未达到0.15°的预定目标，因此默认改为250µs。250µs与100µs的峰值差约0.112°、0.31mm，达到目标。500µs直行/转弯结果作为快速工况验证保留，不能标成默认步长下的完整复测。详细差异和通过状态保存在`car_validation/summary.json`。

新的高性能测试使用500us机械宏步长以控制计算成本；快速段前4.8秒与250us相比最大姿态差0.757°、水平位置差1.10mm、速度差0.0152m/s，未达到0.15°姿态目标。250us只复核该片段，没有完整重跑39秒；高性能工况在250us下尚未完成对100us的收敛检查。面板把500us标成快速探索，250us标成精度复核，报告不把两者混为同一验证范围。

`validation/validation.json`为留出电流检查；`physics_validation.json`检查dq能量、姿态和轮速符号；`noise_profile_validation.json`检查AR稳定性和方差。200Hz PID的综合地形、高速和步长结果保留在`pid_validation/summary.json`；1kHz的新周期与响应验证在`pid_rate_validation/summary.json`。`validate_measured_car`复现当前1kHz完整场景和快速段复核。旧`car_validation/`保存0.7A历史回归，不要把不同时序、限幅及步长合并为同一批证据。

本版适合比较控制实现、噪声和参数敏感度。没有建模开关级纹波、死区、模拟放大器稳定时间、每次ADC先后采样、完整RTOS/I²C抖动、齿槽转矩、温漂或长期随机游走；L、绝对转矩与轮胎接地特性仍需更多实测。架空电流环检查与整车仿真通过，不代表实物已完成落地平衡验证。

方程约定参照[MathWorks Surface Mount PMSM](https://www.mathworks.com/help/mcb/ref/surfacemountpmsm.html)；电压/反电势关系参考[SimpleFOC电压转矩控制说明](https://docs.simplefoc.com/voltage_torque_control)。本目录明确区分实测等效参数、条件推导与未辨识先验。
