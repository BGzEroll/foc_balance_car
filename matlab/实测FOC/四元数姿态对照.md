# 四元数姿态解算对照

运行 `run_quaternion_comparison` 后台计算；完成后运行 `show_quaternion_comparison` 打开曲线与机械真值三维回放。状态、图和指标保存在 `quaternion_validation/`，各次完整仿真保存到带 `attitude_comparison` 后缀的独立结果目录。

比较当前欧拉角互补滤波与 Mahony 风格的六轴四元数互补滤波。四元数采用 `[w x y z]`、机体到世界旋转，世界 X右/Y前/Z上。陀螺使用四元数指数增量积分，重力方向叉积提供比例校正，每步归一化。校正增益为4/s，与旧滤波0.02/5ms的近似时间尺度一致；加速度模长偏离校准后的1g时逐渐降低校正权重，偏差达到20%时关闭重力校正。未加入磁力计、额外电流滤波或陀螺积分偏置补偿。

先用理想三轴运动检查四元数乘法、旋转方向与归一化，再用原生Multibody跑4秒3°倾斜恢复和10秒前进转弯。两组PID、IMU 200Hz、噪声随机种子、FOC、电流上限6A和250µs机械步长相同。算法间差异同时包含姿态运动学和加速度权重策略，不应全部归因于四元数表示。

单独运行示例：

```matlab
balance_setup
run_measured_car('route',false,0,true,250e-6,10,'selected','explore6',0,.005,'quaternion','manual')
```

默认仍使用 `legacy`。运行器每次在内存中更新传感器图块，原SLX不会被保存覆盖。完整综合地形、高速边界及数值收敛尚需单独复测。六轴四元数不能提供绝对航向，偏航仍会随陀螺零偏漂移；模长门控也不能保证识别所有线加速度。结果只证明模型中的表现，不代表实车通过。

## 2026-10-20 对照结果

四次闭环运行均完成且未倒下。指标仅使用真值和控制器日志共同覆盖的时间段，不对末端缺少真值的样本外推。

| 工况 / 指标 | 原算法 | 四元数算法 |
|---|---:|---:|
| 3°恢复：俯仰估计RMS误差 / ° | 0.1613 | 0.2440 |
| 3°恢复：偏航估计RMS误差 / ° | 0.01883 | 0.01525 |
| 3°恢复：真实峰值倾角偏差 / ° | 3.000 | 3.324 |
| 3°恢复：峰值实际Iq / A | 1.028 | 1.074 |
| 前进转弯：俯仰估计RMS误差 / ° | 0.3305 | 0.3347 |
| 前进转弯：偏航估计RMS误差 / ° | 0.05309 | 0.04893 |
| 前进转弯：真实峰值倾角偏差 / ° | 2.030 | 1.840 |
| 前进转弯：峰值实际Iq / A | 0.5860 | 0.5405 |
| 前进转弯：真实末端航向误差 / ° | -0.08328 | -0.07761 |

四元数算法能在现有闭环中运行，在这两条轨迹上偏航估计误差略低；转弯工况峰值倾角、电流略低，但俯仰估计未改善，恢复阶段反而更差。因此保留可选模式，不直接替换默认算法。上述只是单一固定噪声种子的两种温和工况，不是统计显著性或高速/复杂地形优势的证据。

独立理想多轴运动学检查中，四元数整体旋转误差最大约0.000004°，原算法约114.3°；测试包含持续20秒多轴运动和多圈偏航，专门暴露直接按机体陀螺分量积分欧拉角的问题。该数值不代表本次小车轨迹的误差或性能提升。
