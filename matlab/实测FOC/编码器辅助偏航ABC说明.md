# 磁编码器辅助偏航：A / B / C

本实验冻结的是姿态估计器对偏航角速度的积分，**不是偏航PID误差积分**。俯仰互补滤波、PID各层参数、FOC、原有3ms编码器速度低通均保持原设置。A/B/C共用同一编码器转向判据。

运行 `run_encoder_yaw_comparison` 后台计算；完成后运行 `show_encoder_yaw_comparison` 打开同输入离线对照、原生机械闭环图和C方案三维回放。状态与结果在 `encoder_yaw_validation/`，完整机械结果在 `results/*_encoder_yaw/`。`yaw_observer`保存逐帧零偏、判定、角速度和KF方差，便于解释结果。

## 三种方案的精确定义

| 方案 | 确认未转向时 | 检测到转向时 |
|---|---|---|
| A (`yaw_a`) | 用2秒时间常数低通更新等效偏航零偏，yaw仍积分校正后的角速度 | 冻结零偏估计，继续积分 |
| B (`yaw_b`) | yaw严格保持；不动态学习零偏 | 恢复原陀螺角速度积分 |
| C (`yaw_c`) | yaw严格保持；以偏航角速度0作为伪测量，通过标量KF更新零偏 | 零偏只预测不更新；积分扣除估计零偏后的角速度 |

所有方案使用同一个初始航向。A/C的偏置初值为0，不读取注入零偏真值。所有方案保留原始带扰动角速度作为PID微分反馈，本实验只改变航向积分/零偏处理，避免同时改变D反馈混淆效果。陀螺的机体Z分量与世界偏航导数有区别；这里用共同俯仰/横滚估计把陀螺转换为ZYX航向导数。无磁力计，因此这三种方案仍没有绝对航向观测，已经累积的航向误差不会自动恢复到真实方向。

C中只需要一维线性KF，不必再次使用六轴姿态EKF：`omega=gyroYaw-bias`，伪测量为 `omega=0`；等价于测量 `bias=gyroYaw`。零偏按随机游走预测，用Joseph标量形式更新方差。初始零偏标准差0.5°/s，随机游走密度0.015°/s/√s，零角速度伪测量标准差0.15°/s。它们是固定仿真先验，并非实测辨识的统计置信度；连续帧与轮胎误差会使噪声相关。

## 如何确认没有转向

使用实测接口中的MA左、MB右磁编码器观测：左右轮角速度分别是执行器向量15/29项，轮角度是16/30项，不使用指令、机械真值或IMU来决定未转向状态。轮角度需是连续展开值；本模型已有连续量化角度，实机0～2π角度必须先处理跨圈。

```text
encoderYawRate = wheelRadius / wheelTrack * (omegaRight - omegaLeft)
```

半径32.5mm、轮距132.5364mm，右轮更快为正（左转）。用100ms轮角增量窗口确认低速差速，并辅以20ms低通后的速度差作快速释放。进入阈值0.5°/s，退出阈值1°/s，快速退出阈值3°/s；连续满足低速差速150ms后才确认未转向。首次启动至少等待窗口填满与确认结束，不能上电立即假定未转向。阈值之间保留滞回状态。这层滤波只用于检测，不改变原编码器反馈速度滤波或FOC。

“不转向”可以包含直行和倒车，不要求两轮静止。它依赖左右有效轮径接近、编码器方向正确、地面接触且不发生明显侧滑。阈值下的慢转、外力侧滑或整体搬转可能无法识别。检测释放也存在延迟，C在释放前可能把初始真实转动学成零偏；日志和指标会保留这些反例，不把它们算成算法成功。

## 仿真范围

1. 固定输入离线120秒：原有残余零偏，以及额外明确标记的缓慢漂移两组；三方案共享同一组陀螺/编码器输入，便于单独比较估计器。包含常规左右转、低于阈值的0.003rad/s慢转、编码器未感知但车体确实转动的反例。4096计数/周、量化抖动与噪声为教学近似，这不是Multibody或实物验证。
2. 原生Multibody14秒A/B/C三次闭环：0.6m平地前进，4～6秒左转30°，9～11秒右转回原方向，中间有直行段。相同200Hz PID/IMU、250µs机械步长、6A仿真电流指令上限。

为使短时间能看清差异，三次机械闭环均在原噪声模型上额外注入体Z陀螺零偏 `0.25°/s + 0.015°/s² × t`，注入点在量化之前。注入真值只用于生成数据和事后报告，估计器看不到它；实测参数JSON与实机固件不变。这是**零偏漂移压力测试**，不冒充原始实测噪声下的收益；默认噪声表现由离线对照单独列出。本次没有重新跑三组无额外漂移的原生机械闭环。

偏航估计误差、真实末端航向/路程误差、峰值倾角/电流与是否倒下分开记录；同时报告冻结期间实际转过的角度、真角速度超过1°/s时的错误冻结时间。真值只用于评价，不参与判定或滤波。

参数位于 `encoder_yaw_parameters.m`。单独运行：

```matlab
balance_setup
run_measured_car('yaw_test',false,0,true,250e-6,14,'selected','explore6',0,.005,'yaw_c','manual','bias_drift')
```

关于零角速度伪测量的背景：[Improved Planetary Rover Inertial Navigation and Wheel Odometry Performance through Periodic Use of Zero-Type Constraints](https://arxiv.org/abs/1906.08849)。这里是针对当前小车的简化标量偏置KF实现，没有复现该论文的完整导航滤波器。

## 2026-10-21 实际结果

三次14秒原生机械闭环均完成且未倒下，数值指标均有限，但都未通过现有真实末端航向误差2°的门槛。以下全部为上文明确标记的额外零偏漂移压力场景：

| 指标 | A | B | C |
|---|---:|---:|---:|
| 偏航估计RMS误差 / ° | 2.744 | 2.744 | 3.064 |
| 真实末端航向误差 / ° | -5.006 | -5.004 | -5.544 |
| 真实末端路程误差 / mm | -2.549 | -2.772 | -2.086 |
| 真实峰值倾角偏差 / ° | 0.971 | 0.972 | 0.862 |
| 峰值实际Iq / A | 0.581 | 0.559 | 0.571 |
| 确认未转向占全部帧 / % | 0.571 | 2.214 | 0.821 |
| 真角速度大于1°/s时错误冻结 / s | 0 | 0 | 0 |
| 保持期间的真实转角绝对值积分 / ° | 0 | 0.0852 | 0.0336 |
| 末端等效偏航零偏估计 / °/s | 0.000056 | 0 | -0.0397 |

这版判据在闭环中几乎无法持续确认未转向，因此A/C没有学到注入零偏，B也几乎无法保持航向；C没有改善闭环。本结果不证明编码器辅助零速约束无效，更不能证明C一定优于B。

`diagnose_encoder_yaw_gate`仅从已保存日志核对判据，没有再次仿真或重调参数。在避开规定左右转向段的区间内，真实角速度绝对值中位数约0.377～0.422°/s，说明闭环车体已在缓慢漂转；编码器100ms窗口的绝对角速度中位数约0.431°/s，95分位约0.647～0.862°/s，离0.5°/s进入阈值很近。快速差速95分位约2.87～3.04°/s，也接近3°/s退出阈值。虽然约73%～79%的这些帧满足窗口进入阈值，150ms连续确认仍被间断超限打断。这是当前门控低可用率的日志证据，不能把这些区间简单称作“真实未转向”。完整诊断在 `gate_diagnostics.csv/json`。

### 同输入离线对照：收益和反例

下表只取0～55秒的常规左右转向与直行区间；不是机械闭环：

| 航向RMS误差 / ° | A | B | C |
|---|---:|---:|---:|
| 原有小残余零偏+噪声 | 0.117 | 0.072 | 0.291 |
| 额外缓慢零偏漂移 | 0.754 | 2.063 | 0.266 |

因此C在这条离线慢变零偏数据上有效，但固定KF参数和检测释放延迟也会在小零偏情况下引入代价。离线阈值以下的10秒慢转和5秒编码器未感知转动反例中，B/C分别冻结了整个10秒和5秒；A虽始终积分，也可能把未识别的真实慢转逐渐学成零偏。没有一种方案能仅凭“左右轮差很小”保证绝对航向正确。

当前不替换默认算法。若继续改进，应先在真实编码器量化/抖动与闭环数据上验证检测连续性、进入/退出阈值、释放延迟，以及已发生慢漂时的可观性，再决定是否调整判据或加入其他独立约束。简单放宽阈值可能提高冻结率，同时把更多真实慢转当成零偏；不能只追求冻结时间或让估计曲线平稳。

可运行 `show_encoder_yaw_comparison` 查看完整曲线和C的三维真值回放。报告、原始MAT及图保留在各自结果目录；未进行实车验证。
