# 第一次怎么看仿真

你之前看到一直向前走，是因为打开的是“地形”工况。Multibody Explorer显示的是当前这一次的结果，不是14个工况的视频列表。

1. 在MATLAB中打开本目录的`launch_balance_panel.m`，点编辑器上方绿色“运行”；出现“平衡车3D仿真：选择工况”窗口。
2. 工况选“原地转向”，控制器先保留LQR，转矩上限先保留0.10。
3. 点击“运行所选工况，更新3D窗口”，等待计算完成。运行会重新求解动力学，不是只换一个动画文件。
4. 切换到标题含`balance_car_3d_suite`的Multibody Explorer窗口，在动画时间轴旁点击播放。转向工况总共9秒：1～3秒转向60°，5～7秒再回到20°。
5. 想看其他动作，回到选择面板，换工况，再点击运行。只改下拉框或在3D窗口重播，不会切换工况。

## 三种窗口的作用

| 窗口 | 用途 |
|---|---|
| 中文工况面板 | 选动作、选LQR/LQI、发起计算、打开曲线 |
| Simulink方框图 | 查看机械连接、状态测量、控制器和转矩输入；初次观看不必修改 |
| Multibody Explorer | 观看当前计算出的三维运动、改变视角、拖动时间轴 |

在Multibody Explorer中看转向时，选Top/俯视视角更明显。时间轴停在0秒或末尾时，小车静止是正常的，点击播放或拖到1～7秒观察。若打开了多个MATLAB实例或旧的3D窗口，请使用本面板运行时弹出的那个`balance_car_3d_suite`窗口；旧的`balance_car_3d`是之前的基础工程。

## 建议观看顺序

先看“原地转向”，再看“边走边转”，然后“外力推扰”和“起伏地形”。最后分别用LQR和LQI运行“持续扰动”，点“查看所选工况的曲线”，比较路程误差是否回到零。

`run_balance_suite`是批量验证入口，结果保存在`results/suite`；它不会自动为14组结果分别保留可切换的3D标签。日常观看请使用选择面板。
