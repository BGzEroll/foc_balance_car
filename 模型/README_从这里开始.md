# ZD2808 两轮平衡车 · 最终整理版

先打开 `平衡车模型档案.xlsx` 看整体图、尺寸、实测质量、机械参数和文件用途。继续建模打开 `freeCAD工程/平衡车_最终.FCStd`。当前版本日期：2026-10-17。

STL和OBJ只存外形，不携带原生装配关节或完整惯性数据。用于动力学时选URDF/SDF/MJCF及配套参数，不应仅导入整车STL就把它当成可独立转轮的机器人。

STEP包含由作者STL转来的三角面车架和轮毂，未凭空重建成解析曲面，因此约300MB；需要快速查看或仿真时优先使用网格。CAD网格保留完整细节；仿真STL视觉网格已轻量化为车身90000面、左右轮组各40000面，碰撞使用简单几何体。视觉简化不改已显式指定的质量和惯量。

## FreeCAD工程树与操作

```text
01_平衡车整机
  01_车身固定组_277.1g
    01_车架与安装件
    02_电路板与编码器
    03_电池与电池座
    04_左右电机定子
  02_左轮旋转组_62.7g
    轮毂 / 轮胎 / 转子 / 编码器磁铁 / 中轴螺钉
  03_右轮旋转组_62.7g
    轮毂 / 轮胎 / 转子 / 编码器磁铁 / 中轴螺钉
02_参数与使用说明
  运动控制
  坐标与计重说明
  机械参数
  实测质量输入记录
  尺寸标注（默认隐藏）
```

原有PCB器件合成整板，绕组和铁芯归到定子，转子细节归到转子；共23个可见部件。复合形状保留不同材质面，不强行做会改变分件含义的布尔融合。要改PCB单个元件等细节，可打开源数据中的完整R6工程。

选中部件按空格可切换显示；尺寸标注展开后选中所需标注按空格显示。选中运动控制可修改 `Travel`（毫米）、`Heading`（角度）和 `Pitch`（角度）。也可通过FreeCAD“宏→宏”运行同目录的 `打开模型与运动控制.FCMacro`，用按钮和输入框演示；`打开机械参数清单.FCMacro` 可打开带轴线定义的参数表。

运动控制是几何运动关系，不是物理求解；直线距离与原地转向分别演示，不执行任意路径的积分。工程保存姿态为直立零位。

## 单位与坐标

CAD文件：毫米。X沿轮轴、右为正，Y向前，Z向上；地面Z=0，轮轴Z=32.5mm。

仿真文件：米、千克、秒、弧度。X向前，Y向左，Z向上，原点在轮轴中点。位置转换为：

`[x_sim,y_sim,z_sim] = [y_CAD,-x_CAD,z_CAD-32.5] / 1000`

惯量张量亦已旋转到相同坐标，单位kg·m²。两轮关节轴都是仿真坐标的+Y；同号正角速度对应两轮向前滚动。轮胎接触中面间距132.5364mm。

## 质量、质心与惯量口径

整车402.5g = 车身277.1g + 两侧旋转组各62.7g。单侧旋转组包括轮毂20.3g、轮胎20.3g、电机转子21.2g、编码器磁铁0.6g、中轴螺钉0.3g。电机定子、电机安装螺钉及编码器板属于车身。

电机安装螺钉8颗共4.8g已经计入车身惯性参数；原外观未额外添加这8颗实体，工程树单列其计重记录。车架45.4g和电池座36.9g均包含各自用户说明中的连接螺钉，不应再次加重。护件没有单独称重，不额外赋予质量；编码器安装螺钉是否在1g内沿用此前口径。

基础质量属性来自FreeCAD/OCCT实体的体积、质心和惯量矩阵，按分件实测质量归一化并作平行轴换算。STL来源先转闭合实体参与计算。转子磁体、PCB材料等内部密度分布仍采用等效几何假设。轮胎惯量用外径65mm、径向壁厚8.2mm的等效环，装配视觉外形保持已匹配版本；二者截面差异和情形对照保存在计算依据中。

车身俯仰惯量：过车身重心的平行轮轴为3.11848e-4 kg·m²；绕实际轮轴为6.81607e-4 kg·m²；勿重复添加平行轴项。单侧轮组自转惯量为2.99679e-5 kg·m²。

整车绕重心竖直轴偏航惯量为9.54563e-4 kg·m²。绕轮轴中点竖直轴为9.54564e-4 kg·m²。理想原地差速转向再加轮组滚动自转折算项2.49190e-4，合计1.20375e-3 kg·m²。URDF、MJCF等文件已经显式建模两轮自转，因此采用各刚体惯量，**不把等效总偏航惯量重复填进车身惯量**。

Excel中的质量合计、平行轴换算和等效偏航公式可以重算；基础质心与几何惯量仍为本次快照。改动几何或质量分布后，需要重新执行相应CAD质量属性计算并重新导出仿真参数，不能只改Excel就认为全部文件会自动同步。

## MATLAB

在MATLAB运行 `仿真模型/MATLAB/打开模型.m`。使用Robotics System Toolbox导入URDF并显示模型；本机R2025b已验证导入成功，左右轮组质量均为0.0627kg。rigidBodyTree预览固定基座，不能据此当作浮动基座的平衡车接触仿真。

本机未安装Simscape Multibody，所以未生成或声称验证SLX动力学工程。脚本中留有 `smimport` 入口；安装对应工具箱后可导入，再设置浮动基座、重力、轮地接触和控制器。

## ROS2与Gazebo

将 `balance_car_description` 文件夹放进ROS2工作空间的src下，在该工作空间构建并加载环境后运行：

```bash
colcon build --packages-select balance_car_description
source install/setup.bash
ros2 launch balance_car_description display.launch.py
```

需要ament、robot_state_publisher、joint_state_publisher_gui、RViz2等依赖。描述文件与网格路径已检查，当前电脑没有运行ROS2/RViz或Gazebo，因此尚未进行这些引擎中的实机启动验证。RViz只显示关节姿态。

通用URDF的根坐标位于轮轴，创建物理仿真实例时使轮轴约高于地面0.0325m，并留少量初始间隙；SDF及MJCF初始值用0.0335m。ROS的某些KDL使用方式不处理根link惯量；要做浮动基座物理仿真，应由对应物理引擎加载全部三刚体参数，勿把固定基座运动学解释为整车动力学。

Gazebo交付 `Gazebo_SDF/model.sdf`，有质量、惯量、两个转动关节和简化碰撞体，未添加版本绑定的驱动插件。需要按所用Gazebo版本配置控制和接触，不包含已经调好的平衡控制器。

## MuJoCo与训练

在准备好的Python环境安装MuJoCo后，在 `仿真模型/MuJoCo` 运行：

```bash
python run_demo.py
```

配套 `load_model.py` 通过Python读取XML及二进制网格再交给MuJoCo，避免部分Windows原生文件接口对中文路径的处理问题。MuJoCo子文件夹的几何文件独立齐全，可单独复制。

模型有自由基座和两个轮轴铰链，左右各一个直接转矩输入，单位N·m；没有把电流、KV或电压假设成转矩。`data.ctrl[:]` 是控制器或策略输出的接入点。演示默认零转矩，小车会自由运动或倒下，不会自行平衡。

此版用MuJoCo 3.16.0通过编译及1000步、1秒的零转矩数值验证，没有数值警告；总质量0.4025kg。偏航约束速度代入引擎动能矩阵反算的等效惯量与清单相对差异约1.57e-7。此验证证明文件和惯性关系可用，不是闭环稳定性或实物接触准确性的验证。

用于强化学习时，还需按任务设置观测、奖励、终止条件、控制周期、复位姿态、转矩限制和域随机化。接触摩擦1、扭转/滚动摩擦等为示例值，未按实物辨识；电机电气与驱动器动态、延迟、传感器噪声和真实驱动限幅尚未建模。已使用简单碰撞体避免PCB和网格细节拖慢求解。
