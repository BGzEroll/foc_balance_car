# R6：分称轮组后的机械参数估算

最新输入：轮毂20.3g、轮胎20.3g（均为单件）；轮胎外径65mm、径向壁厚8.2mm。每侧轮组质量40.6g，替换旧41.2g，两侧合计少1.2g，因此整车清单更新为402.5g。旧R4.2和R5结果保留。

## 参数清单与坐标定义

X 沿左右轮轴，Y 向前，Z 向上。以下均为直立姿态。车身指不随车轮自转的部分（包含电机定子）；单侧旋转组指该侧轮毂、轮胎、转子、编码器磁铁与中轴螺钉；整车包含车身与两侧旋转组。

| 参数／运动及轴线 | 估算值 | 含义 |
|---|---:|---|
| 整车总质量（车身＋左右旋转组） | 402.5 g | 全部已计重部件 |
| 车身质量（不含左右旋转组） | 277.1 g | 含车架、定子、PCB、电池等随车身俯仰的部件 |
| 单侧旋转组质量（随轮自转） | 62.7 g | 单侧轮毂、轮胎、电机转子、编码器磁铁、中轴螺钉 |
| 车身重心至轮轴的竖直高度 | 36.53 mm | 直立姿态；平衡模型常用高度 h |
| 整车重心离地高度 | 57.65 mm | 直立姿态；包含两侧旋转组 |
| 车身俯仰惯量：过车身重心的 X 平行轴 | 0.000311848 kg·m² | 只计车身；过车身重心且平行于左右轮轴 |
| 车身俯仰惯量：实际左右轮轴 X | 0.000681607 kg·m² | 只计车身；已含从车身重心移至轮轴的平行轴项 |
| 单侧旋转组自转惯量：该侧轮轴 X | 2.99679e-05 kg·m² | 一侧随轮自转部件；左右各一份，不是整车偏航惯量 |
| 整车偏航惯量：过整车重心的竖直 Z 轴 | 0.000954563 kg·m² | 全部部件作为整体绕此竖直轴旋转；不附加相对车身的轮组自转能量 |
| 整车偏航惯量：过轮轴中点 O 的竖直轴 | 0.000954564 kg·m² | 用于原地转向中心 O；全部部件作为整体，已从整车重心作平行轴换算 |
| 原地差速转向：轮组滚动附加等效惯量 | 0.00024919 kg·m² | b²/(4r²) × (J左＋J右)，折算到偏航角速度 |
| 原地差速转向：总等效偏航惯量 | 0.00120375 kg·m² | 整车绕 O 的偏航惯量＋轮组滚动附加项；直立、刚性、纯滚动、忽略微小惯性积耦合 |
| 轮胎滚动半径 r | 32.5 mm | 按外径65mm；未计承载变形 |
| 左右轮胎接触中面间距 b | 132.536 mm | 用于理想差速纯滚动关系，不是轮组原点间距 |

俯仰与偏航是不同轴线的运动，不能混用惯量。车身俯仰惯量满足 I_A = I_C + M·l²，l 是车身重心到轮轴线的垂距；若方程已有 I_C + M·l²，不应再把 I_A 代入 I_C。

偏航采用整车质量分布。过整车重心的竖直轴与过轮轴中点 O 的竖直轴几乎重合，但仍分别列出并作平行轴换算。O=(0,0,32.5)mm，原地转向时其在地面的投影为理想转向中心。

理想纯滚动时，左右轮自转角速度幅值为 b/(2r) 倍偏航角速度，因此 I_yaw_eq = I_whole_z_O + b²/(4r²)·(J左+J右)。这是由动能折算的等效值；轮组自身随整车偏航的惯量已经在 I_whole_z_O 中，附加项只计相对车身的滚动自转。忽略极小惯性积耦合。若方程显式包含两轮自转动能，应使用刚体偏航惯量并分别加入轮组项，避免重复计算。

原地转向结果不包含轮胎接地变形、摩擦阻力、驱动损耗，也不是电机轴侧的等效负载惯量。

## 是否用FreeCAD计算

是。此版统一调用FreeCAD/OCCT的闭合实体 `Volume`、`CenterOfMass`、`MatrixOfInertia`。车架和轮毂原为STL，先转成封闭Part实体再取属性。轮胎的等效圆环、螺钉的等效圆柱，也由FreeCAD生成并取同样的属性。

FreeCAD返回几何分布在单位等效密度下的惯量；脚本按各部件实测质量归一化，再做刚体组合和平行轴换算，转成kg·m²。因此既使用FreeCAD自身的计算能力，也明确处理实测质量分组和单位。不是直接把整车总质量乘一个惯量公式。

## 轮胎8.2mm厚度的处理

采用外径65mm、径向厚8.2mm的均匀圆环近似，等效内径48.6mm。轮胎宽度沿用作者模型28mm；绕轮轴的圆环惯量与宽度无关，其他方向的惯量会受宽度影响。

轮胎自身轴向惯量：J_tyre = 0.5×0.0203×(0.0325²+0.0243²) = 1.6714411×10⁻⁵ kg·m²。FreeCAD实体计算与该解析值交叉核对。

原轮毂座约52mm、原装配胎内径约52.1mm，与上述等效内径并不一致。可能涉及自由状态与装配拉伸或截面差异，目前没有足够截面数据区分。因此惯量用等效环，已匹配的装配几何不强改，也不声称48.6mm孔可直接无变形套在52mm座上。

作为对照，保留当前装配胎截面，并分别使用CAD转子、D35圆盘或薄环，6种假设下单侧旋转惯量约2.8e-05～3.21e-05 kg·m²。这是情形对照，不是置信区间。当前基准J约3e-05，替换此前轮胎/轮毂未分称时的3.41×10⁻⁵估计。

## 其余分布假设与边界

- PCB、电池座、定子等合称组合内部按实体体积等效分配质量；铜、铁、塑料与FR4的真实密度分布未分别标定。
- 转子21.2g包含内壁永磁体等实际部件，但CAD未单独精细建立内壁磁体，等效归入转子几何。轴承未按内外圈分别细分。
- 车架45.4g包含4颗连接螺钉，等效分布到车架；电机安装螺钉按每颗0.6g及孔位估算形状。两侧电机沿用一台拆机样本。
- 电芯每节44.6g用18×65圆柱分布；支柱按各自合称值等分。编码器安装螺钉是否在1g称重内仍沿用此前口径。
- 以上是几何假设下的初始参数，尚未通过悬挂、摆振或运动辨识验证，质量精度也受实物秤影响。

## 文件与模型

- `平衡车_R6_轮组分称及机械参数.FCStd`：更新质量和参数快照的原生模型，运动关系保留。`MechanicalEstimates`对象可查看SI参数。
- `lqr_mechanical_params.py` / `.m`：Python和MATLAB的SI参数。
- `机械参数估算.json`：完整组件分解、惯量张量和6种截面对照。
- `recalculate_mechanics.py`：本次计算脚本，使用FreeCAD自带Python运行，网格转实体缓存若缺失则重建。

R6模型的Motion.Track已统一为接触中面轮距132.536mm；旧动画131.536mm是轮组原点距离。参数快照不会自动随着所有改件重算，模型内的MassChangedSinceCalculation可提示质量变化，几何改变仍须重新计算。

这份结果可作为平衡车LQR机械部分的初始输入。尚未计算LQR增益，也未验证闭环稳定性；还需要电机转矩/驱动输入关系、状态约定和采样周期。
